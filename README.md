# 🏡 Plannco — Home Decoration & Interior Design

**Plannco** is a responsive home decoration and interior design company landing page. It showcases property and interior design inspiration, presents furniture-related services, and provides contact sections for visitors interested in home decoration solutions.

🌐 **Live Demo:** https://plannco.vercel.app/

📂 **GitHub Repository:** https://github.com/felixkai34/Plannco

## 📖 About the Project

Plannco is a front-end website concept for a home decoration business. It brings together visual inspiration, company information, service highlights, and contact options in one web page.

The design focuses on presenting interior spaces through a visual gallery and helping visitors explore different categories, including houses, decorations, furniture, and office interiors.

This project demonstrates the use of HTML, CSS, Bootstrap, and JavaScript to build a structured, interactive business landing page.

## ✨ Features

* **Responsive Navigation** — Navigate between the website's main sections.
* **Hero Banner** — Introduces the Plannco home decoration brand.
* **Property & Interior Gallery** — Browse images of houses, decorations, furniture, and office spaces.
* **Category Filtering** — Filter gallery items by category.
* **Lightbox Image Viewing** — Open gallery images in a larger viewing interface.
* **Company Introduction** — Present the business concept and background.
* **Furniture Services Section** — Showcase service highlights such as fast service and affordable solutions.
* **Contact Call-to-Action** — Provides a direct phone call link.
* **Newsletter Form UI** — Displays name and email fields for visitor interaction.
* **Back-to-Top Control** — Return to the top of the page conveniently.

## 🚀 Getting Started

This project uses static front-end files and does not require a package installation for its basic setup.

### 1. Clone the repository

```bash
git clone https://github.com/felixkai34/Plannco.git
```

### 2. Open the project folder

```bash
cd Plannco
```

### 3. Run the website

Open `index.html` directly in your browser.

For a local development server, you can use the Visual Studio Code **Live Server** extension or another static file server.

### 4. Explore the website

* Navigate through the main sections.
* Filter the property gallery.
* Open gallery images.
* Review the furniture services.
* Test the contact and newsletter interface.

## 🖼️ Gallery Categories

The gallery groups its images into four categories:

* **Houses** — Residential properties and living spaces.
* **Decoration** — Interior decoration inspiration.
* **Furniture** — Furniture and interior elements.
* **Office** — Office and workspace interiors.

Visitors can select a category to explore the associated gallery images.

## 🌐 Deployment

The project is deployed on Vercel.

**Live Website:** https://plannco.vercel.app/

To deploy your own copy:

1. Push the project to a GitHub repository.
2. Import the repository into [Vercel](https://vercel.com/).
3. Configure it as a static website.
4. Set the output directory to the project root if required by the deployment configuration.
5. Deploy the site.

Because the project uses static HTML, CSS, and JavaScript, a build step is not required for the basic version.

## ⚠️ Project Notes

* The website currently uses placeholder text in some sections. Replace it with accurate company information before using the site for a real business.
* The newsletter form is a front-end interface; collecting and storing subscriptions requires a backend or form service.
* Contact details should be verified before publishing the website for customers.
* Bootstrap, jQuery, and other externally hosted resources require an internet connection when loaded from their respective CDNs.
